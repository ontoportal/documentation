# Joining the Federation

The OntoPortal Federation connects OntoPortal-based portals so that users can browse ontologies and search for classes and concepts across several portals from a single interface. It was first released in December 2024 by AgroPortal, EcoPortal, EarthPortal and BiodivPortal.

Joining the Federation is a collaborative process between portal administrators. In short, it involves:

* **Running an up-to-date OntoPortal-based portal**, since the federation works at the user interface level and relies on all portals sharing the same API.
* **Exchanging API accounts** with the other federated portals, so that each portal can identify the calls coming from the others.
* **Agreeing on shared conventions**, in particular for ontologies hosted on several portals: the same acronym is used everywhere and one "canonical" portal is the reference for each of them.
* **Taking part in the Federation governance**, which is organised by its partners and framed by a memorandum of understanding.
